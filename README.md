# Postcards Home

A web application for creating digital postcards that combine photos, captions, music, and locations into memorable snapshots of life.

## Features

- User authentication with Supabase
- Create and save postcards
- Image upload and storage
- Mood-based music selection
- Life segment organization
- Inventory view
- Download and share postcards

## Tech Stack

- HTML
- CSS
- JavaScript
- Supabase
